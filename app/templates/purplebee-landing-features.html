Purple Bee 기능

실사용 중심으로 바로 도움이 되는 기능을 우선 제공합니다. 모든 기능은 “대화 + 첨부 자료 + 최근 문맥”을 함께 활용하도록 설계했습니다.

대화형 문제 해결

  • 짧은 질문부터 복합 요구까지 의도 파악
  • 오류 원인 후보 정리 + 우선순위 제안
  • 후속 질문 자동 제안으로 탐색 속도 향상

문서/코드 분석

  • 파일 내용 요약, 핵심 문장 추출, 비교
  • 코드/로그/설정 파일을 함께 연결해 설명
  • 문제 재현 순서와 수정 포인트를 구체화

사용자 메모리

  • “기억해줘/저장해줘” 요청을 사용자별로 저장
  • 필요 시 답변 문맥에 반영
  • 개별 삭제/전체 삭제/확인 다이얼로그 지원

온디바이스 추론

  • 브라우저에서 모델 실행 (WebGPU/WASM)
  • 첫 질문 워밍업 안내 + 지연 시간 표시
  • 추론 타임아웃/락으로 멈춤 현상 완화
현재 Purple Bee는 무료 플랜으로 제공됩니다. 결제 기능 없이, 대화 품질/속도/안정성 개선을 우선 진행합니다.
