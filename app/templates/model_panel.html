모델 관리

현재 모델을 선택하고, 비활성화 여부를 관리하고, 모델 구조와 이슈를 확인하는 화면입니다.

모델 상세
운영 가이드
  • 항상 현재 모델 하나만 활성 상태로 유지하는 것이 안전합니다.
  • 응답 품질을 건드릴 때는 먼저 평가를 돌리고, 그 다음 학습을 이어가면 좋습니다.
  • 최신 모델이라도 품질이 낮으면 바로 배포하지 말고 회귀 평가부터 확인하세요.
모델 생성
새 모델 버전은 현재 최신 모델을 복사해서 시작합니다.

배포

브라우저 패키지 생성부터 Hugging Face 업로드, Cloudflare 재배포까지 연결된 작업을 수행합니다.

배포 설정
배포 워크플로우
일반적으로는 패키징 → HF 업로드 → Cloudflare 배포 순서로 진행합니다.
배포 메모
  • 초기화 실패가 잦으면 `WASM 우선` 설정으로 두는 편이 더 안정적입니다.
  • HF 업로드 후 Cloudflare를 다시 배포해야 웹사이트에서 최신 설정을 읽습니다.
  • 모델 자체 품질이 낮으면 배포는 성공해도 답변은 여전히 부자연스러울 수 있습니다.

정리

운영에 꼭 필요하지 않은 파일만 `Cleanup_Archive`로 이동합니다. 바로 삭제하지 않고 보관하는 방식이라 복구도 가능합니다.

주의 사항

  • 필요하면 Cleanup_Archive에서 다시 원래 위치로 복원할 수 있습니다.
