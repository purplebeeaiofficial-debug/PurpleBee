Purple Bee
소개 기능 안전 아키텍처 요금

웹사이트, 준비물 설치, 기여 클라이언트를 역할별로 나눠 안정성을 확보합니다.

Purple Bee는 한 화면에 모든 책임을 몰아넣지 않고, 웹 UI·실행 자산·기여 구독·실제 하드웨어 감지를 각각 알맞은 계층으로 분리합니다.

웹사이트 계층

질문 입력, 최근 대화, 준비물 설치 상태, 플랜 안내, 기여 시간 예약 같은 사용자 경험을 담당합니다.

AI 준비물설치 여부, 업데이트 필요 여부, 예상 용량, 삭제 기능을 제공합니다.
플랜 업그레이드Free, Basic, Plus, Pro와 기여 기반 구독 구조를 안내합니다.

실행 자산 계층

모델, tokenizer, manifest, health, endpoints 같은 자산을 버전 단위로 관리하고 동기화합니다.

설치 관리자 흐름필요한 파일만 내려받고, 이미 최신이면 재설치를 막습니다.
삭제와 재설치브라우저 저장소와 연결된 폴더를 함께 정리할 수 있습니다.

기여 구독 계층

분산 작업 큐, 기여 시간 적립, 패널티, 구독 활성화는 별도 서버와 클라이언트 조합으로 처리합니다.

중앙 서버작업 분배, 상태 저장, 점수 계산, 플랜 활성화를 담당합니다.
큐 재시도노드 실패 시 작업을 다시 배정하고 반복 실패는 격리합니다.

네이티브 클라이언트

브라우저가 확인할 수 없는 실제 CPU·GPU·RAM·디스크 정보를 읽고, 유휴 시간에만 기여 작업을 수행합니다.

실제 하드웨어 감지CPU 모델, GPU 모델, 실제 메모리 용량과 저장 공간을 수집합니다.
자원 상한 제어CPU/GPU 사용률 제한과 사용자 활동 복귀 시 자동 일시정지를 적용합니다.
