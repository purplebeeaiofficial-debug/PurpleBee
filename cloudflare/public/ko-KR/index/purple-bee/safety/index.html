안전 및 신뢰성

Purple Bee는 모델 성능 향상과 함께 오작동 방지를 동시에 관리합니다. “멈춤 방지”, “응답 품질 회귀 평가”, “데이터 삭제 제어”를 핵심 안전 축으로 운영합니다.

실행 안정성

온디바이스 추론은 모델 타임아웃과 단일 추론 락을 적용해, 첫 질문 이후 UI가 멈추는 문제를 줄입니다. 엔진 워밍업을 통해 초기 지연도 완화합니다.

Runtime Guard

품질 회귀 평가

학습 과정에서 고정 프롬프트 세트(인사/자기소개/정의/직답/능력/후속질문)를 step 단위로 반복 평가하고, 결과를 모델 패널에 즉시 반영합니다.

Regression Eval

사용자 데이터 제어

최근 대화 저장 ON/OFF, 메모리 개별 삭제/전체 삭제, 대화방 삭제 전 확인창을 제공합니다. 사용자 요청 시 저장 정보는 즉시 제거할 수 있습니다.

User-controlled Storage

알려진 한계

100M 클래스 모델은 대형 클라우드 모델 대비 표현력 한계가 있습니다. 따라서 instruction 데이터 품질, 샘플링 파라미터, fallback 최소화 전략을 지속 개선합니다.
