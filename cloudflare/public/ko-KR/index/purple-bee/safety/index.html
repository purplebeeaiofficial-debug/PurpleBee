Purple Bee
소개 기능 안전 아키텍처 요금

안전성은 기능보다 먼저 확인합니다.

Purple Bee는 준비 상태를 먼저 점검하고, 불안정한 실행을 억지로 밀어붙이지 않는 방향으로 제품을 설계하고 있습니다.

실행 전 확인

설치 여부, 업데이트 필요 여부, 브라우저 저장 기능, 워커 지원 여부를 먼저 검사합니다.

설치 상태 우선준비가 덜 된 상태에서는 답변보다 상태 안내를 먼저 보여줍니다.
자산 무결성필수 파일이 누락된 경우 업데이트 필요 상태로 되돌리고 재설치를 유도합니다.

기여 구독 안전성

분산 기여는 웹사이트가 아니라 네이티브 클라이언트가 맡고, 상한과 일시정지 규칙을 먼저 적용합니다.

CPU/GPU 상한기여 작업은 사용자가 정한 상한 안에서만 동작합니다.
사용자 활동 감지사용자가 다시 작업을 시작하면 기여 작업은 자동으로 일시정지됩니다.
작업 재분배노드 실패 시 작업은 자동으로 다른 기기에 재할당됩니다.
