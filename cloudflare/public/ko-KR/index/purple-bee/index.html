Purple Bee는 접속한 사용자 기기에서 직접 추론하는 온디바이스 AI입니다.

서버 연산을 최소화하고 대화 속도를 높이기 위해, Purple Bee는 브라우저(WebGPU/WASM)에서 모델을 실행합니다. 문서, 코드, 스크린샷을 함께 이해하고 최근 대화 문맥을 반영해 답변합니다.

왜 Purple Bee인가

OpenAI 제품 소개 페이지의 정보 흐름을 참고해, Purple Bee도 “핵심 가치 → 실제 활용 → 안정성 → 기술 근거” 순서로 구성했습니다.

대화 흐름 유지

최근 대화와 사용자 메모리를 결합해 질문 의도에 맞는 응답을 우선 생성합니다.

실무형 분석

문서 요약, 로그 점검, 코드 설명, 문제 해결 순서 제안까지 한 화면에서 처리합니다.

비용 효율

서비스 기본 구조는 Cloudflare 정적 배포 + 클라이언트 추론 중심으로 운영비를 낮춥니다.

로드맵

현재는 안정화 중심 단계이며, 이후 모델 품질과 제품 범위를 확장합니다.

  • Phase 1 — 응답 안정화 첫 질문 지연 안내, 모델 타임아웃 제어, 재질문 멈춤 이슈 완화, 사용자별 대화/메모리 유지.
  • Phase 2 — 품질 향상 회귀 평가 자동화(인사/정의/직답/후속질문), 학습 데이터 정제, instruction 데이터 보강.
  • Phase 3 — 도구 통합 이미지/문서/음성 분석 파이프라인 고도화, 설정·기억·대화 관리 UX 강화.
