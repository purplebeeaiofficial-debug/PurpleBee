시스템 아키텍처

Cloudflare 정적 배포 + 사용자 기기 직접 추론 구조를 기본으로 합니다. 사용자 요청이 들어오면 브라우저에서 모델 추론을 수행하고, 서버는 정적 자산/메타 정보 전달에 집중합니다.

Cloudflare Worker Browser ONNX Runtime WebGPU / WASM Session Memory
1. 사용자 질문 입력 입력 텍스트, 첨부 파일, 최근 대화 문맥을 클라이언트에서 통합합니다.
2. 런타임 매니페스트 조회 브라우저는 `/api/runtime/browser-manifest`로 현재 모델 자산 경로와 런타임 설정을 가져옵니다.
3. 온디바이스 모델 초기화 ONNX Runtime(WebGPU/WASM) 세션을 준비하고 워밍업을 수행합니다.
4. 추론 실행 + 응답 스트리밍 사용자 기기에서 모델을 실행하고, 응답을 타이핑 애니메이션으로 스트리밍 렌더링합니다.
5. 사용자별 저장 Google 로그인 사용자는 대화/메모리를 사용자 키 기준으로 저장하여 새로고침 후에도 복원합니다.
6. 관리용 학습 파이프라인 학습/재학습은 관리 컴퓨터에서 별도로 수행하고, 결과 아티팩트만 배포 경로로 반영합니다.
