# Transformer 구조 요약

Transformer는 문장을 순서대로만 읽는 대신, 한 문장 안의 여러 단어가 서로 어떤 관련을 가지는지 동시에 살펴보는 self-attention 구조를 핵심으로 사용한다. 이 방식 덕분에 긴 문장에서 멀리 떨어진 단어 관계도 비교적 잘 반영할 수 있고, 병렬 처리에 유리해서 대규모 학습에 잘 맞는다.

실전에서는 attention만으로 끝나지 않고, 토크나이저 품질, 학습 코퍼스 정제, 학습률 스케줄, 평가셋 설계, 반복 억제 같은 주변 요소가 결과를 크게 바꾼다. 모델 크기가 작을수록 이런 주변 요소의 영향이 더 커져서, 데이터 품질과 평가 루프를 잘 잡는 것이 중요하다.
